# GCP Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a public cloud computing platform developed by Google. It provides services for computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, and application development. Organizations can use Google Cloud to build, deploy, and manage applications and infrastructure through Google's cloud infrastructure.

## Global Infrastructure

Google Cloud organizes its infrastructure into geographic regions and zones. Regions are independent geographic areas, while zones are isolated locations within regions. Resources can also have global or regional scopes depending on the service. This structure allows organizations to place workloads closer to users, improve availability, and distribute resources across different failure domains.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and manage virtual machines, storage, databases, networking resources, security settings, monitoring tools, and other cloud services through the console. The console provides a centralized interface for managing projects and cloud resources.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that run on Google's infrastructure. Organizations can use these virtual machines to host applications, websites, development environments, and other workloads.

### 2. Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data such as files, backups, media, and application data. It provides scalable storage for different types of workloads.

### 3. Cloud SQL

Cloud SQL is a fully managed relational database service. It supports popular database engines and reduces the operational work required to maintain database infrastructure.

### 4. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy, manage, and scale containerized applications. It combines Google Cloud infrastructure with Kubernetes orchestration capabilities.

## Three Advantages

1. **Strong AI and machine learning capabilities** – Google Cloud provides a wide range of artificial intelligence and machine learning services and infrastructure for developing and running AI workloads.

2. **Kubernetes and container expertise** – Google Cloud provides Google Kubernetes Engine (GKE), a managed Kubernetes platform that makes it easier to deploy and manage containerized applications.

3. **Global network and infrastructure** – Google Cloud provides a worldwide infrastructure of regions and zones that can help organizations build scalable and highly available applications.

## Typical Enterprise Use Cases

Google Cloud is commonly used for artificial intelligence and machine learning, data analytics, containerized applications, web and application hosting, database workloads, large-scale data processing, and digital services. Organizations can also use Google Cloud services to develop modern cloud-native applications using containers, Kubernetes, serverless technologies, and managed databases.
