
# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of on-demand services for computing, storage, databases, networking, security, analytics, and other IT needs. Organizations can use AWS resources over the internet without having to purchase and maintain all of their own physical infrastructure.

## Global Infrastructure

AWS operates a global cloud infrastructure organized into geographic Regions and Availability Zones. AWS Regions are separate geographic areas, while Availability Zones are isolated locations within a Region that are designed to provide high availability and fault tolerance. This infrastructure allows organizations to deploy applications closer to their users and build systems that can continue operating even if part of the infrastructure experiences a failure.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create and configure resources, monitor services, manage security settings, view billing information, and control their cloud infrastructure through the console without needing to perform every operation through the command line.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads in the cloud. Users can select different instance types based on their computing requirements.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve files and other types of data. It is commonly used for backups, media files, application data, and data archives.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) is a managed relational database service. It simplifies database deployment, operation, backups, and maintenance for supported relational database engines.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources. It allows administrators to manage users, roles, permissions, and policies to help protect cloud resources.

## Three Advantages

1. **Wide range of services** – AWS provides many cloud services covering computing, storage, databases, networking, security, analytics, and other technologies.

2. **Global infrastructure** – AWS has a large worldwide infrastructure that allows organizations to deploy applications in different geographic locations and design highly available systems.

3. **Scalability and flexibility** – AWS resources can be increased or decreased based on workload requirements, allowing organizations to adapt to changing demand.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for hosting websites and applications, data storage and backup, database systems, software development and testing, analytics, disaster recovery, and large-scale digital services. Companies can combine multiple AWS services to build scalable and highly available cloud architectures.
