# Azure Research

## Brief Overview

Microsoft Azure is a public cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, databases, networking, security, analytics, artificial intelligence, and application development. Azure allows organizations to build, deploy, and manage applications and infrastructure using Microsoft's global cloud platform.

## Global Infrastructure

Azure operates through a global infrastructure consisting of geographic regions and datacenters. Azure regions contain datacenters that provide access to cloud services, while availability zones can provide physical separation within supported regions. This infrastructure helps organizations deploy applications close to their users and design systems with high availability and resilience.

## Cloud Management Console

The Azure portal is a web-based management interface for Azure resources and services. Administrators can use the portal to create and configure virtual machines, databases, storage, networking resources, security settings, monitoring tools, and other cloud services. The portal also provides dashboards and management tools for monitoring cloud environments.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides scalable virtual servers that allow organizations to run applications and operating systems in the cloud. It supports different operating systems and virtual machine configurations based on workload requirements.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data. It can be used for documents, images, videos, backups, logs, and other files.

### 3. Azure SQL Database

Azure SQL Database is a fully managed relational database service based on Microsoft SQL Server technology. It provides database capabilities while reducing the need for organizations to manage the underlying infrastructure.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, applications, authentication, and access to cloud resources and services.

## Three Advantages

1. **Strong Microsoft integration** – Azure works closely with Microsoft technologies such as Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID.

2. **Enterprise capabilities** – Azure provides services for security, identity, governance, compliance, hybrid cloud environments, and large enterprise workloads.

3. **Global scalability** – Organizations can deploy applications and services across Azure's worldwide infrastructure and scale resources according to their requirements.

## Typical Enterprise Use Cases

Azure is commonly used by enterprises for Windows-based applications, Microsoft 365 integration, databases, virtual desktops, application hosting, hybrid cloud environments, identity management, data analytics, artificial intelligence, and enterprise infrastructure migration. Organizations that already depend heavily on Microsoft technologies can use Azure to extend their existing IT environment into the cloud.
