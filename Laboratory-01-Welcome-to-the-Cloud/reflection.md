# Mission Reflection

This laboratory activity helped me understand how cloud engineers work with Linux environments. Using KillerCoda, I was able to access an Ubuntu server without installing a virtual machine on my own computer. I learned how to check the operating system, kernel, CPU, memory, and available disk space using Linux commands.

One of the most useful parts of the activity was learning how to organize files and directories from the terminal. Creating the Notes folder and the about-me.md file showed me how Linux can be used to manage a workspace efficiently. I also learned that documenting commands and results is important because it makes technical work easier to understand and verify.

The activity also introduced me to the importance of GitHub as a cloud computing portfolio. Instead of keeping my laboratory outputs only on my computer, I can store and organize them in a repository that can be accessed and reviewed online. This is similar to how professionals maintain documentation and project files.

Overall, I learned that cloud computing is not only about using cloud services. It also requires basic Linux knowledge, organization, documentation, and version control. These skills will be useful in the next laboratory activities as I continue learning about cloud infrastructure and other technologies.
