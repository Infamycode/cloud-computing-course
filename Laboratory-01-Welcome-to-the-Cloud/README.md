# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I explored the Linux system, collected system information, created a workspace, and documented my activities using Markdown.

## Objectives

- Access a Linux environment through KillerCoda.
- Explore and navigate Linux.
- Gather basic system information.
- Create and organize directories and files.
- Document technical activities using Markdown.
- Build a professional Cloud Computing portfolio.

## Activities Performed

I launched an Ubuntu 24.04 Linux playground in KillerCoda and created my user account. I checked the operating system, kernel version, CPU, memory, and disk space. I also created the required Notes folder and the about-me.md file.

## Linux Commands Used

- `cat /etc/os-release` – checked the Linux distribution.
- `uname -r` – checked the kernel version.
- `lscpu` – displayed CPU information.
- `free -h` – checked memory.
- `df -h` – checked disk space.
- `pwd` – displayed the current directory.
- `mkdir` – created directories.
- `cat` – viewed file contents.

## Skills Learned

I learned how to work with a Linux terminal, inspect system resources, organize files and directories, and document technical work. I also gained experience using KillerCoda as a cloud-based Linux environment.
